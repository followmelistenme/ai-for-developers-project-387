# 01: Убрать «Как это работает» из шапки

Status: ready-for-agent
Category: enhancement
State: open

**Source:** GitHub issue #9 «Убрать из шапки "Как это работает"» от 2026-11-21.

## Agent Brief

**Category:** enhancement
**Summary:** Удалить ссылку «Как это работает» из шапки главной страницы, сохранив сам блок с тремя шагами на странице.

**Current behavior:**
В шапке главной страницы есть навигационная ссылка «Как это работает»,
которая ведёт к одноимённому блоку ниже. На узких экранах ссылка скрывается
стилями, но на десктопе отображается. Браузерные тесты главной проверяют
наличие ссылки, переход по ней и её скрытие на мобильных ширинах. Спецификация
главной описывает ссылку в шапке как согласованное решение.

**Desired behavior:**
Шапка главной страницы содержит только название сервиса и доступные для
данной страницы элементы навигации (ссылка «Для владельца», кнопка
«Перейти к записи»). Ссылки «Как это работает» в шапке нет ни на одной
ширине экрана. Блок «Как это работает» с тремя шагами остаётся на главной
и доступен обычной прокруткой; его заголовок, содержимое и идентификатор
остаются прежними. Остальная навигация и мобильная компоновка не меняются.

**Key interfaces:**
- Навигация в шапке главной страницы: перестаёт рендерить ссылку «Как это работает».
- Стили, предназначенные только для этой ссылки: удаляются вместе с правилом её скрытия на мобильных экранах.
- Браузерные тесты главной: больше не требуют ссылку в шапке и переход по якорю; вместо этого проверяют отсутствие такой ссылки в шапке и наличие блока с шагами на странице.
- Спецификация главной: в согласованных решениях шапка описывается без этой ссылки, мобильное исключение про её скрытие удалено.

**Acceptance criteria:**
- [ ] На десктопной и мобильной ширине в шапке главной нет ссылки с доступным именем «Как это работает».
- [ ] Блок «Как это работает» с заголовками «Выберите тип встречи», «Найдите удобное время» и «Подтвердите запись» остаётся видимым на главной при прокрутке.
- [ ] Кнопки «Перейти к записи», страница записи, ссылка «Для владельца» и отсутствие горизонтальной прокрутки на 320 и 390 px работают как раньше.
- [ ] Браузерные тесты главной обновлены: удалена проверка перехода по ссылке в шапке и проверка её скрытия на телефоне; добавлена проверка отсутствия ссылки в шапке и наличия блока с шагами.
- [ ] Мёртвые стили ссылки удалены, спецификация главной приведена в соответствие с новым решением.
- [ ] `mise run check` проходит.

**Out of scope:**
- Изменение содержимого, порядка шагов или заголовка блока «Как это работает».
- Удаление других пунктов шапки и изменение маршрутов `/booking` и `/owner`.
- Изменения бэкенда, API и правил бронирования.
