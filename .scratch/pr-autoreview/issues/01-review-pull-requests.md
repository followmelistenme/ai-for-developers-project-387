# 01. Независимое авторевью pull request

Status: ready-for-agent

Авторевью помогает сопровождающему проверить изменения и критерии приёмки
до слияния PR. Новые PR должны получать независимую проверку по `REVIEW.md`.

## Критерии приёмки

- Workflow работает на `pull_request`, отменяет ревью предыдущего коммита
  при обновлении того же PR и ограничивает время работы.
- Критерии ревью и исполняемый код загружаются из базовой ветки. Модель
  получает только ограниченный контекст изменений, оркестратор публикует
  результат с идентификатором проверенного коммита.
- Лимит на один PR проверяется и резервируется до обращения к модели.
  События сверх лимита обходятся без нового вызова модели.
- Шаблон PR запрашивает критерии и проверки, риск и способ отката.
  README описывает настройку, публикацию результата и пропуски.
