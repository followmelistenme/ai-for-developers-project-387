# Проверять доступность календаря по расписанию

Status: ready-for-agent

GitHub Actions ежедневно проверяет прежний Render-деплой календаря и позволяет
повторить проверку вручную. Адрес можно переопределить через `APP_URL`.

## Критерии приёмки

- Запуск ежедневно в 10:23 по Тбилиси и вручную из основной ветки. Тайм-аут
  задания — пять минут. Активный запуск не отменяется новым.
- Проверяются главная страница и каталог опубликованных типов встреч. Пустой
  список допустим. Если первая проверка не проходит, предусмотрена повторная
  попытка с запасом на пробуждение Render.
- Отчёт доступен в сводке задания и артефакте `app-monitor-report`. Для
  подтверждённого сбоя OpenCode сверяет отчёт с `.scratch/` и GitHub Issues,
  включая закрытые. Повторный сбой с известной задачей получает ссылку на неё.
- Публикация в GitHub Issues разрешена по расписанию и при явном включении в
  ручном запуске. Ошибка сверки и сомнительное совпадение остаются в отчёте.
