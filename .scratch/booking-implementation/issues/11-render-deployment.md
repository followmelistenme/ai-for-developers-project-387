### 2026-11-20 — проверка автоматического запуска

README и тикет опубликованы коммитами 99b42b2 и a2532fd; pre-push
`mise run check` прошёл (41 passed, 28.1s). Раннюю ошибку agnix в тексте
тикета исправили без отключения правила: запись домена с начальным знаком
at распознавалась как импорт несуществующего файла.

После push a2532fd список deploys/events по-прежнему содержит только
первый успешный деплой a6214f9. get_service подтверждает autoDeploy=yes
и autoDeployTrigger=commit, но это пока не подтверждает работу webhook.
Согласно документации Render, автоматические deploys требуют подключённого
Git-провайдера; для публичного Git URL без подключения используется ручной
деплой. Пользователю передана проверка GitHub-привязки в Dashboard:
подключение Git-провайдера через доступные инструменты MCP не поддерживается.
Первый опубликованный сервис остаётся live, повторный deploy вручную
при включённом autoDeploy не запрашивался.

### 2026-11-20 — решение пользователя

Пользователь выбрал: «Оставить пока работающий сайт без проверки автодеплоя».
Срез закрывается с работающим и проверенным первым деплоем. Настройка
autoDeploy=yes сохранена; работоспособность автоматического запуска
не объявляется подтверждённой. Дальнейшая проверка привязки GitHub и
webhook отложена. Сервис не перезапускается вручную; финальный
документационный коммит содержит [skip render].
