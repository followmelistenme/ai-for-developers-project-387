# 01: Убрать «Как это работает» из шапки главной

Status: ready-for-agent

**Source:** [Спецификация изменения](../spec.md),
[триажный бриф issue #9](../../homepage/issues/01-remove-how-it-works-link.md),
[существующая спецификация главной](../../homepage/spec.md).

**What to build:** Гость открывает главную на любом экране и видит в шапке
только название сервиса, ссылку «Для владельца» и кнопку «Перейти к записи».
Ссылки «Как это работает» в шапке больше нет ни на десктопе, ни на телефоне.
Блок «Как это работает» с тремя шагами остаётся на странице и находится
обычной прокруткой; его заголовок, содержимое и идентификатор не меняются.
Остальная навигация и мобильная компоновка работают как раньше.

**Blocked by:** None (can start immediately).

- [ ] На десктопной и мобильной ширине, включая 320 и 390 px, в шапке главной нет ссылки с доступным именем «Как это работает».
- [ ] Блок «Как это работает» с заголовками «Выберите тип встречи», «Найдите удобное время» и «Подтвердите запись» остаётся на главной и доступен прокруткой; заголовок, содержимое и идентификатор блока сохранены.
- [ ] Две кнопки «Перейти к записи», страница записи с возвратом на главную, ссылка «Для владельца», страница владельца и отсутствие горизонтальной прокрутки на 320 и 390 px работают как раньше.
- [ ] Браузерные тесты главной обновлены: удалены проверка перехода по ссылке в шапке и проверка её скрытия на телефоне; добавлены проверки отсутствия ссылки в шапке по доступному имени и наличия блока с шагами на странице.
- [ ] Стили, существовавшие только для удалённой ссылки вместе с правилом её скрытия на мобильных экранах, удалены; стили блока с шагами и остальной шапки не изменены.
- [ ] Спецификация главной приведена в соответствие с новым решением: описание шапки не содержит ссылку «Как это работает», мобильное исключение про её скрытие удалено.
- [ ] `mise run check` проходит.
