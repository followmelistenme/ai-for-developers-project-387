# 12. Ограничить число опубликованных типов встреч

Status: ready-for-agent
State: closed

Правило и поведение интерфейса согласованы в [спецификации MVP](../../booking-mvp/spec.md).

- [x] В календаре одновременно опубликовано не более пяти типов встреч.
- [x] При заполненном лимите шестой тип остаётся черновиком. Владелец может создать и сохранить новые черновики.
- [x] Владелец видит причину отказа рядом с черновиком и может повторить публикацию после снятия публикации или удаления одного из пяти типов.
- [x] При конкуренции разных черновиков за последнее место публикуется ровно один. Повтор для уже опубликованного типа возвращает этот же тип.
- [x] Поведение описано в TypeSpec и проверено через HTTP API и браузер.

## Реализация

Бэкенд проверяет лимит и публикует черновик в одной критической секции.
Ответ HTTP 409 с кодом `publication_limit_reached` содержит сообщение,
которое интерфейс показывает рядом с черновиком.
