# 01: Убрать ссылку «Как это работает» из шапки главной

**What to build:** Гость видит в шапке главной только название сервиса,
ссылку «Для владельца» и кнопку «Перейти к записи» на любой ширине экрана.
Пункт «Как это работает» полностью исчезает из навигации, а информационный
блок с тем же названием остаётся на главной вместе с якорем, вступительным
текстом и тремя шагами записи на звонок. Изменение остаётся только в
интерфейсе: переход к записи, страница владельца, правила бронирования
и контракт API не меняются.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] На главной нет ссылки с точным названием «Как это работает» ни на десктопе, ни при ширине 320 и 390 пикселей; скрытого пункта с таким названием в разметке тоже нет.
- [ ] Заголовок «Как это работает», якорь раздела и все три шага записи на звонок остаются видными на главной; на телефоне шаги идут в колонку.
- [ ] Кнопка «Перейти к записи» в шапке и на первом экране по-прежнему ведёт на страницу записи с возвратом на главную; ссылка «Для владельца» ведёт на страницу владельца, а состав шапки на страницах записи и владельца не меняется.
- [ ] При ширине 320 и 390 пикселей нет горизонтальной прокрутки.
- [ ] Существующие браузерные сценарии главной проверяют отсутствие удалённой ссылки на десктопе и на телефонах, видимость раздела и трёх шагов, а также сохраняют проверки кнопок и отсутствия горизонтальной прокрутки; новые тестовые прослойки не добавляются.
- [ ] Оформление, использовавшееся только для удалённой ссылки, включая правило её скрытия на узких экранах, удалено; стили раздела, кнопок и остальной навигации сохранены.
- [ ] Спецификация главной более не обещает ссылку в шапке и её скрытие на телефоне: вместо этого зафиксировано полное удаление пункта при сохранении информационного блока.
- [ ] Стандартные проверки репозитория проходят; если какая-то проверка не запущена, это явно сообщается.
