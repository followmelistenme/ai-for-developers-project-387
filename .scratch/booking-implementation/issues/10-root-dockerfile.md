## Answer

Корневой Dockerfile собирает фронтенд и бэкенд закреплёнными Node/Go,
затем запускает Go и готовый SPA в одном Alpine-контейнере без привилегий.
Корневой .dockerignore ограничивает контекст исходниками и manifest-файлами.
FRONTEND_DIR включает выдачу SPA через fs.FS; API и документация сохраняют
свои ответы, неизвестные API-маршруты и отсутствующие assets возвращают 404.
PORT задаёт внутренний порт, BACKEND_PORT имеет приоритет; default — 8080.
