# Domain Docs

## Размещение

Проект использует единый доменный контекст:

- `GLOSSARY.md` в корне — термины предметной области.
- `docs/adr/NNNN-kebab-case.md` — архитектурные решения.

Бэкенд и фронтенд используют общий глоссарий.

## Перед исследованием кода

Прочитайте `GLOSSARY.md` и ADR, относящиеся к текущей задаче.

Если документы отсутствуют, продолжайте работу без предупреждений
и предложений создать их заранее. Skill `domain-modeling` создаёт
их по мере согласования терминов и решений.

## Терминология

Используйте термины глоссария в задачах, предложениях, коде и тестах.
Если нужного понятия нет, проверьте необходимость нового термина
и отметьте пробел для `domain-modeling`.

## Архитектурные решения

Если предложение противоречит существующему ADR, явно укажите
номер решения, противоречие и причину пересмотра.
