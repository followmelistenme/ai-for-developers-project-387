# Автотриаж новых обращений GitHub

Status: ready-for-agent

Новые обращения в GitHub Issues должны получать предварительный разбор от
агента. Тикеты с установленными статусами готовности должны пропускаться.

## Критерии приёмки

- Workflow запускается при открытии issue и пропускает обращения ботов,
  аккаунтов младше 30 дней, готовые тикеты и обращения с метками
  `needs-info` и `wontfix`.
- OpenCode получает ограниченный текст обращения и не имеет инструментов.
  Workflow может читать репозиторий и публиковать комментарий в issue.
- Готовность проверяется повторно перед публикацией. Повторный запуск
  не создаёт дубликат комментария.
- Проверены новое обращение и готовый тикет. README описывает запуск,
  ограничения, настройку и порядок проверки в GitHub.
